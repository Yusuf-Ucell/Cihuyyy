Risikonya Disini

Temukan risiko di balik setiap langkah SOP

Tempel isi SOP atau unggah file teks. Sistem memecahnya menjadi langkah kerja, menandai risiko operasional, kepatuhan, dan finansial, lalu menghitung skor dengan rubrik 5x5 ala ISO 31000.

Cara kerja

  1. Dokumen dipecah per langkah kerja.
  2. Setiap langkah diperiksa terhadap pustaka risiko.
  3. Kemungkinan dan dampak dinilai, skor dihitung otomatis.
  4. Anda menerima atau menolak tiap temuan sebelum laporan dibuat.

Versi demo ini memakai mesin aturan yang berjalan di browser dan tidak mengirim data ke mana pun. Pada mode AI, teks SOP dikirim ke backend server yang terhubung ke API Claude, OpenAI, atau Gemini. Versi ini menerima teks yang ditempel atau file .txt. Pastikan Anda memiliki izin untuk mengirim dokumen ke penyedia AI yang dipilih.
